# Suggested submission form entries

**Journal:** Complex & Intelligent Systems

**Article type:** Original Article

**Suggested track:** Intelligent Data Analytics -- Machine Learning

**Title:** Query Dual Dynamics Delta: Read-Driven Modulation of Delta-Rule Writes in Fixed-Capacity Fast-Weight Memory

**Keywords:** fast-weight memory; Delta rule; linear attention; adaptive intelligent systems; workload adaptation; online subspace learning

**Short description:** This work introduces an online fast-weight memory operator in which a compact trace of historical queries modulates later residual Delta-rule writes. The method treats read and write streams as interacting dynamics and improves fixed-capacity recall when future demand differs from write exposure, while retaining constant state in sequence length.
