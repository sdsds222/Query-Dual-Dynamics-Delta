# Complex & Intelligent Systems submission checklist

## Ready files

- `READY_TO_UPLOAD/QD3_CIS_anonymous_manuscript.pdf`: anonymous review PDF with figures and tables embedded.
- `READY_TO_UPLOAD/QD3_CIS_manuscript_source.zip`: complete editable LaTeX source.
- `READY_TO_UPLOAD/QD3_CIS_title_page.pdf`: author information and all declarations.
- `READY_TO_UPLOAD/QD3_CIS_cover_letter.pdf`: journal-specific cover letter.
- `READY_TO_UPLOAD/QD3_CIS_reproducibility.zip`: code, prepared arrays, manifests, validation grids, and per-seed results.
- `READY_TO_UPLOAD/QD3_CIS_optional_figures_600dpi.zip`: optional separate RGB figure files if the submission system requests them.

## Journal checks completed

- Manuscript prepared for the journal's double-blind review process.
- Author names, affiliations, e-mail addresses, ORCID, acknowledgements, contributions, and declarations are outside the anonymous manuscript.
- Abstract length: 233 words; required range: 150--250.
- Keywords: 6; required range: 4--6.
- Figures and tables appear in the manuscript near their first discussion.
- Editable LaTeX source and bibliography are included.
- Figure filenames follow the `Fig1`, `Fig2`, `Fig3` convention.
- Color figures use labels and distinct visual structure in addition to color.
- Funding, competing interests, ethics, consent, data, materials, code availability, and author contributions are included on the title page.
- The manuscript and editorial PDFs compile without undefined citations, undefined references, or overfull boxes.

## Author checks before pressing Submit

- Confirm the article type displayed by Editorial Manager is `Original Article` or the closest equivalent.
- Select the `Intelligent Data Analytics / Machine Learning` track when a track is requested.
- Confirm both authors approve this exact CIS version and author order.
- Confirm the corresponding-author e-mail and ORCID entered in Editorial Manager match the title page.
- Confirm the manuscript is not under consideration by another journal.
- Confirm institutional open-access eligibility separately when Springer requests the publishing agreement after acceptance.

## Suggested upload order

1. Anonymous manuscript source ZIP.
2. Anonymous manuscript PDF, if the system requests a separate review PDF.
3. Title page.
4. Cover letter.
5. Reproducibility package as Supplementary Information.
6. Separate figure files only if requested; the figures are already embedded in the manuscript.
